# Codex Micro 1.85B 代码审查报告

审查日期：2026-08-07

## 审查范围

- 首页六 Agent 与颜色状态；
- 中央 0.8/5/10/15/20 秒长按状态机；
- 六快捷页和录音启动；
- 四向遥控映射和退出；
- 录音波形、刷新频率和停止逻辑；
- 任务提示音与静音逻辑；
- BLE/USB 连接状态、重新配对；
- 额度缓存、Companion 设置和 NVS；
- 常亮、IMU 运动唤醒、翻面静音和已关闭的自动旋转；
- 回归脚本、完整编译、应用区刷写和启动日志。

## 已发现并修复

1. `updateWaveform()` 在声明前被 20ms 定时器调用，导致编译失败；已增加前置声明。
2. 快捷页点击“录音”只发送瞬时 `ACT10`，不会保持录音，也不会显示波形；已增加 UI→主程序录音启动请求。
3. 波形同时被 20ms 定时器和 80ms UI 更新重复刷新；已只保留 20ms 路径。
4. 录音开始、停止仍调用提示音；已删除调用及无用接口。
5. 恢复出厂误用任务完成音；已移除。
6. 当时中央不足 0.8 秒的轻触会被强制当成快捷页；先修为不进入页面。当前 V3 又按
   最终操作定义恢复为短点发送 `ACT12`，0.8 秒以上才进入长按分级。
7. 触摸滑出中央区域后长按状态可能残留；已增加 `PRESS_LOST` 清理。
8. 首页显示 1–6，协议必须发送 Codex Desktop 的零基槽位 `AG00`–`AG05`。
9. 黄色等待状态先命中红色错误判断；已统一为先判断黄色，并直接使用原始颜色，和任务提示音判断一致。
10. `connected` 把 USB 连接也当成蓝牙连接，导致未连接时可能显示“未同步额度”；已增加独立 `bleConnected`，蓝牙未连接且无缓存时显示“等待连接”。
11. 同一刷新里错误、等待、完成可能连续播放三套声音；已改成报错 > 等待 > 完成的单音效优先级。
12. 已删除旧双击/三击计数、无效超时标志和永远为 false 的 UI 状态，避免与当前长按状态机再次冲突。
13. 已彻底移除 USB Vendor HID 源码、构建环境、USB/BLE 聚合发送和相关实验文档；USB 只保留供电、刷写和串口。
14. 新增 `companionReady` 会话状态；只有 Companion 本次蓝牙连接实际发送过合法数据，首页才进入“未同步额度”，否则显示“等待连接”。

## 当前确认正常

- 普通刷写只写应用区 `0x10000`，不擦除 NVS；
- 10 秒重新配对只删除 BLE bond，不清额度和设置；
- 20 秒恢复出厂才擦除整个 NVS；
- 自动旋转调用已关闭；
- 屏幕通电期间常亮；
- 所有按钮、录音、遥控和恢复出厂均无点击音；
- 仅任务状态和开机自检播放声音；
- 录音波形以屏幕中心为中轴，20ms 更新，安静时保持动态；
- 缺字动态标题整行隐藏，不显示方框或问号；
- 摇杆上/右/下/左映射分别为新任务、前进、侧边栏、后退。

## 非故障但保留的技术债

- 自动旋转算法与陀螺仪旋转函数仍保留在源码中，但当前 `updateImu()` 不调用它们；这是为了以后可以恢复，不影响当前界面方向。
- `esp-idf-size --ng` 与当前工具版本不兼容，会打印警告；PlatformIO 随后使用自己的尺寸检查并成功生成固件，不影响固件。
- NVS 第一次使用或刚恢复出厂后，Preferences 会打印 `NOT_FOUND`；表示暂无缓存命名空间，不是启动失败。
- 提示音由同步 I2S 音调函数播放，播放期间主循环短暂等待。现在每轮只播放一套，阻塞已受控；若未来需要完全无阻塞，可改成音频队列。
