# Codex Macro32 V3 代码与实机审查记录

审查日期：2026-08-12

## 本次版本边界

- 第二版保持在基线 `7601fbf`，本次只修改第三版。
- 日常 Codex 控制、Agent 状态和额度同步继续走 BLE Vendor HID 与 Companion 特征。
- USB 提供 `Codex Macro32 Mic` 48 kHz、16 位、单声道输入和一个维护 CDC。
- 维护 CDC 不传 Codex 命令、额度或录音数据，只允许刷写工具让 ESP32-S3 进入 ROM 下载器。
- USB 键盘、USB Vendor HID、USB 扬声器、自动旋转和按钮点击音保持关闭。

## 已完成代码检查

- 首页六 Agent、中央额度环、40px 额度数字、重置时间和中央电量行均保留。
- 额度环按剩余额度显示绿色、黄色或红色。
- 未连接、重置配对中或尚未完成认证时显示“等待连接”；BLE 已连接并完成认证但没有额度时才显示“未同步额度”。
- 首页中央短点发送当前输入，0.8、5、10、20 秒长按分级和各页面返回逻辑保留。
- 六快捷页、四向遥控、录音独占页和真实麦克风动态波形保留。
- 无按键音；任务完成、等待同意和报错使用独立提示音，USB 录音期间延后播放。
- Companion 连续写包不会在 GATT 写回调内额外通知，避免六任务同步中途断开。
- macOS 自动输入选择默认开启，插线选择设备麦克风，拔线恢复此前输入，并尊重手动改选。
- Companion GUI、CLI 和登录自启共用进程锁，启动失败或异常退出时会释放锁。
- V3 固件版本标识已修正为 `3.0.0-waveshare-1.85b`。

- 板载麦克风产生真实非零录音；最终构建把 ES7210 数字增益校准为 +18 dB。
- 重新配对后 Companion 特征可读，额度与 6 个任务数据包全部写入成功，连接未中断。

## 刷写状态

最终 V3 已于 2026-08-12 通过 ROM 下载模式写入当前设备，写入范围仅为 App 分区
`0x10000`，esptool 完成写后哈希校验。设备随后成功枚举 `Codex Macro32 Mic` 和维护 CDC；
48 kHz 单声道与 macOS 默认输入选择均已实机确认。

本次之后可由 `flash.command` 通过维护 CDC 自动触发下载模式，不再需要 BOOT 操作；普通更新
仍只写 `0x10000`，保留 NVS、蓝牙绑定、额度缓存与 Companion 设置。写入后使用 ESP32-S3
看门狗复位退出原生 USB-JTAG ROM 下载器，避免 RTS 硬复位后仍停留在 ROM。
