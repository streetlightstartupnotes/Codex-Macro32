# Codex Macro32 V3 完整使用说明书

适用设备：Waveshare ESP32-S3-Touch-LCD-1.85B（360×360 圆形触摸屏）  
适用固件为 Codex Macro32 V3，BLE 控制 + USB Audio 麦克风版。
文档核对日期：2026-08-12

当前仅支持并测试 macOS；Windows 与 Linux 不在支持范围。所有命令从本项目目录运行，
不依赖作者电脑上的绝对路径。

## 1. 设备定位

Codex Micro 是 Codex 的蓝牙桌面控制器，用于查看六个 Agent 状态、切换 Agent、执行常用命令、操作四向遥控、启动语音录入和查看额度。

设备正常工作需要：

- 设备已开机并完成固件启动；
- Mac 上的 Codex 和 Companion/额度同步程序正常运行；
- 设备与 Mac 已完成蓝牙配对；
- 需要显示额度时，Companion 已取得额度并同步到设备。

## 2. 开机、常亮与关机

### 2.1 开机

设备上电后依次初始化屏幕、触摸、QMI8658、ES8311 输出、ES7210 双麦克风、蓝牙 HID 和额度缓存。启动完成后进入首页并开始蓝牙广播。

正常启动串口会出现：

```text
QMI8658 ready
Audio ready: ES8311 output + ES7210 dual mic + I2S + amplifier GPIO9
USB_MIC_START rate=48000 bits=16 channels=1 speaker=0 synthetic=0
CODEX_MACRO32_V3_READY
```

### 2.2 屏幕策略

- 设备通电期间保持固定工作亮度；
- 不自动降亮；
- 不自动熄屏；
- 自动旋转已关闭，所有页面保持默认方向；
- 设备移动时只执行无害的屏幕唤醒逻辑，不发送 Codex 命令。

### 2.3 关机

短按设备的硬件 PWR 键关机。PWR 键属于硬件电源锁存，固件不把它当作普通功能键。

## 3. 首页

### 3.1 六个 Agent 球

外围有六个完整圆形按钮，编号 1–6，1 在顶部，之后顺时针排列。

| 操作 | 结果 |
|---|---|
| 点击 1–6 | 切换到对应 Agent，发送 `AG01`–`AG06` |
| 长按某个 Agent | 中央显示该 Agent 的状态、任务标题、工作区和运行时间 |

Agent 整颗按钮使用状态颜色，不是只改边框：

| 颜色 | 状态 |
|---|---|
| 蓝色/呼吸 | 正在运行 |
| 绿色 | 已完成 |
| 黄色 | 等待用户处理 |
| 红色 | 出错 |
| 灰蓝色 | 未分配或没有状态 |

动态标题和工作区会先经过字体检查。只要包含设备字库不支持的字符，该行就整行隐藏，不会显示方框、口口口、乱码或问号占位。

### 3.2 中央额度环

| 当前状态 | 中央显示 |
|---|---|
| 已同步额度 | 剩余百分比，例如 `85%` |
| 已同步重置时间 | 圆环内下方显示，例如 `重置 3天 05时` |
| 已连接但没有额度 | `未同步额度` / `等待额度` |
| 蓝牙未连接或尚未完成配对认证 | `等待连接` |
| 未连接但有历史缓存 | 缓存仍保留在 NVS，重新连接前不显示 |

中央环的填充比例对应剩余额度。连接状态优先于缓存额度：只有 BLE 已连接并完成配对认证后才显示额度或“未同步额度”；重置配对、等待认证和断开期间统一显示“等待连接”。连接指示点为青色时表示 BLE 已连接；黄色表示等待 BLE。USB 麦克风不参与 Codex 命令或额度传输，也不会把 USB 插线误判为蓝牙已连接。

中央底部显示紧凑电池图标与百分比。图标、填充和百分比的全部边界都位于 150px 中央圆盘内，不与外环或六个 Agent 按钮重叠；录音、快捷、摇杆和详情页会自动隐藏电量行。

## 4. 中央长按分级操作

从首页按住中央区域，不要松手；界面会根据持续时间切换预览。看到需要的页面后松手，即选择该模式。

| 按住时间 | 预览 | 松手结果 |
|---:|---|---|
| 不足 0.8 秒 | 无模式选择 | 发送当前输入，`ACT12` |
| 0.8–4.9 秒 | `快捷操作` / `6` / `松开启动` | 进入六快捷页 |
| 5–9.9 秒 | `摇杆` / `4` / `松开启动` | 进入四向遥控页 |
| 10–14.9 秒 | 六个球全部消失，显示 `重新连接` / `10` / `松开重连` | 清除蓝牙绑定并重新广播 |
| 15–19.9 秒 | `恢复出厂`、倒计时、`继续按住` | 松手仍按重连处理；继续按到 20 秒才恢复出厂 |
| 20 秒 | `恢复出厂` / `00` / `正在重启` | 擦除 NVS 并重启 |

长按过程中如果手指滑出中央触控区，系统会取消本次选择、恢复六个球并回到首页，避免卡在预览状态。

## 5. 六快捷页

首页长按中央 0.8 秒后松手进入。该页面不会自动退出。

| 编号 | 显示 | 协议命令 | 用途 |
|---:|---|---|---|
| 1 | 快速 | `ACT06` | 快速操作 |
| 2 | 同意 | `ACT07` | 同意等待请求 |
| 3 | 拒绝 | `ACT08` | 拒绝等待请求 |
| 4 | 分支 | `ACT09` | 创建/进入分支操作 |
| 5 | 录音 | `ACT10` 按下 | 进入锁定录音界面 |
| 6 | 发送 | `ACT12` | 发送当前内容 |

当检测到等待处理状态时，“同意”会绿色强调，“拒绝”会红色强调；检测到任务完成时，“分支”会绿色强调。

退出方法：点击中央一次返回首页。

## 6. 录音

### 6.1 从快捷页启动

1. 进入六快捷页；
2. 点击“录音”；
3. 设备发送 `ACT10` 按下信号；
4. 立即进入独占录音界面；
5. 录音保持开启，不需要持续按屏幕；
6. 按一次实体 BOOT 键停止，设备发送 `ACT10` 松开信号。

### 6.2 用实体 BOOT 键启动

| 操作 | 结果 |
|---|---|
| 按住 BOOT | 开始录音 |
| 松开 BOOT | 停止录音 |
| 第一次短按松开后 350ms 内再次按下 | 进入免按住/锁定录音 |
| 锁定录音时再按一次 BOOT | 停止录音 |

### 6.3 录音界面

录音期间隐藏首页、六个 Agent、额度、连接点和其他操作，只显示：

- `录音  MM:SS` 计时；
- 屏幕中央 29 条青蓝色动态波形；
- 波形固定以屏幕中心 `y=180` 为中轴；
- 20ms 更新一次，约 50 FPS；
- 安静时也有持续而柔和的基线动画；
- 说话越响，波形越高、越亮。

### 6.4 录音声音策略

录音开始和停止均不播放按键音。所有按钮、Agent、中央长按和遥控操作也都没有点击音。

## 7. 四向遥控页

首页长按中央 5 秒后松手进入。

界面由四个对称弧段、箭头、中文文字和中央“退出”圆组成。箭头与文字已向内收，位于距中心约 118px 的位置。

| 方向 | 显示 | 发送动作 |
|---|---|---|
| 上 | `^` + `新任务` | 摇杆上推，`angle=0.75` |
| 右 | `>` + `前进` | `ENC_CC`，`action=2` |
| 下 | `v` + `侧边栏` | 摇杆下推，`angle=0.25` |
| 左 | `<` + `后退` | `ENC_CW`，`action=2` |

触摸规则：

- 中央半径 62px 内：退出遥控页；
- 半径 72–170px：有效方向区；
- 横向位移更大时按左右处理；
- 纵向位移更大时按上下处理；
- 点击中央一次返回首页。

## 8. 蓝牙与重新配对

### 8.1 正常连接

开机后设备自动广播 Vendor HID 和 Companion 服务。连接成功后可接收 Agent 状态、额度、同步间隔和声音设置。

### 8.2 10 秒重新连接

在首页按住中央 10 秒，看到六个球全部消失和“重新连接”后松手。设备会：

1. 停止广播；
2. 断开现有蓝牙连接；
3. 删除所有 BLE bond；
4. 清空白名单；
5. 重新开始广播。

该操作不会擦除额度缓存和 Companion 设置。

### 8.3 20 秒恢复出厂

继续按住中央直到 20 秒。设备会擦除整个 NVS 并重启，因此会删除：

- 蓝牙绑定；
- 额度缓存；
- Companion 同步设置；
- Companion 声音设置。

重启后设备自动开启蓝牙广播，需要重新配对。

## 9. 提示音

设备没有普通按键音，只根据任务状态播放提示：

| 状态颜色 | 事件 | 音效含义 |
|---|---|---|
| 绿色 | 首次进入完成状态 | 明亮上行完成音 |
| 黄色 | 首次进入等待处理状态 | 温和双音提醒 |
| 红色 | 首次进入错误状态 | 低沉警告音 |

同一状态持续不变时不会重复播放；只有从其他状态首次进入该颜色时播放。设备启动后保留一次启动自检音。

同一次刷新里若多个 Agent 同时进入不同状态，只播放一套音效，优先级为：报错 > 等待处理 > 完成。

屏幕朝下且 Z 轴稳定低于 `-0.78g` 时静音；翻回屏幕朝上并高于 `0.60g` 后恢复。Companion 也可以关闭或开启声音。

## 10. 额度同步

额度通过 Companion 同步并写入 NVS。正常刷应用固件只写 `0x10000`，不会擦除 NVS，因此不会主动丢失额度缓存、设置或蓝牙绑定。

额度一直显示“未同步额度”时检查：

1. 蓝牙是否已连接；
2. Companion 是否正在运行；
3. Companion 是否成功读取 Codex 额度；
4. 同步程序是否选中了当前设备；
5. 必要时在 V3 固件目录运行 `一键额度同步.command`，或在 Companion 中点击“立即同步”。

## 11. USB 麦克风

- 插线后继续由 BLE 控制 Codex，USB 同时负责供电/充电和音频输入；
- macOS 输入设备名称为 `Codex Macro32 Mic`；
- Companion 默认启用通用自动选择：插线后设为系统默认输入，拔出后恢复此前输入；连接期间若用户手动改选则尊重用户选择；
- 格式固定为 48 kHz、16 位、单声道、仅输入；
- 音频来自设备板载 ES7210 双麦克风，不是合成音，也不是 Mac 自带麦克风；
- ES7210 使用 30 dB 模拟增益和 +18 dB 数字增益，用于匹配板上微型麦克风的实际输入电平；
- USB 不暴露键盘、Vendor HID 或扬声器；仅额外保留不承载 Codex 数据的 CDC 维护串口；
- Mac 正在使用麦克风流时，本地任务提示音自动暂停，避免被麦克风收进去；
- 新版 V3 的 CDC 维护串口允许 `flash.command` 自动让 S3 进入 ROM 下载器，无需按键；从不含该维护串口的旧固件首次迁移时，仍需先进入一次 ROM 下载模式。

## 12. 常见问题

### 出现口口口或方框

当前静态中文已经限制在自定义字库范围内；动态 Agent 标题遇到缺字会整行隐藏。若静态界面仍出现方框，应记录具体页面和文字，不要用问号占位代替。

### 中央轻触没有发送

首页中央短点应立即发送当前输入。只有按住至少 0.8 秒后松手才会进入快捷页。如果
短点没有反应，先确认 ChatGPT Desktop 已连接设备，并在 Codex Micro 设置中检查
`ACT12` 的发送动作。

### 5 秒以后无法继续到 10/20 秒

当前版本的 5 秒阶段只显示摇杆预览，不会提前隐藏中央触控区，因此可以继续按到 10 秒或 20 秒。

### 点击录音没有波形

确认已刷入当前版本。当前代码使用 `takeRecordingStartRequest()` 把快捷页的录音点击交给主程序，由主程序保持 `ACT10` 按下并进入录音界面。

### 波形不动

波形由独立 20ms LVGL 定时器更新，即使环境安静也有基础动态。如果完全静止，说明 UI 定时器没有运行或设备没有进入录音状态。

### 无声音

检查设备是否屏幕朝下、Companion 声音开关是否关闭，以及启动日志是否包含 `Audio ready`。

### Mac 看不到 Codex Macro32 Mic

确认使用支持数据的 USB 线，并确认刷入的是 `usb-mic/waveshare-1_85b-usb-mic` 环境。先拔插一次数据线，再到“系统设置 → 声音 → 输入”查看。若维护串口仍存在，直接运行 `flash.command` 重刷；只有旧固件连维护串口也没有时，才需要先进入一次 ROM 下载模式。

## 13. 构建、检查与刷写

以下命令均在 `firmware/Codex-Micro-3.0` 目录执行。

回归检查：

```bash
./scripts/check-regressions.sh
```

编译 V3 USB 麦克风版：

```bash
cd usb-mic
pio run
```

全新克隆第一次构建时不要直接指定单独的 `-e waveshare-1_85b-usb-mic`。默认命令会先
运行 `prepare-bluedroid`，随后再生成 USB 麦克风固件。

构建、检查并执行普通升级：

```bash
./flash.command
```

脚本只向 `0x10000` 写入应用固件，并使用看门狗复位返回应用。不要在普通升级中擦除
NVS。只有明确需要恢复出厂时才允许清除 NVS。

## 14. 当前代码验证结果

2026-08-12 已完成：

- 修复 `updateWaveform()` 缺少前置声明导致的编译失败；
- 修复快捷页“录音”只发瞬时命令、不进入录音页面的问题；
- 删除录音开始/停止按键音；
- 删除恢复出厂误用任务完成音；
- 删除录音波形的重复刷新路径，只保留 20ms 定时器；
- 恢复首页中央短点发送 `ACT12`，0.8 秒以上才进入长按分级；
- 增加触摸丢失后的长按状态清理；
- 回归检查通过；
- PlatformIO 完整编译通过；
- 刷写脚本只向 `0x10000` 写入 V3 应用区，不擦除 NVS、蓝牙绑定、额度缓存或 Companion 设置；
- V2 锁定文件与 `7601fbf` 一致；
- V3 普通恢复构建与 USB 麦克风构建均完整编译通过；
- 从 Git 暂存索引导出的干净目录完成首次两阶段构建，不依赖本机缓存或忽略文件；
- USB 描述符固定为输入型 48 kHz/16 位/单声道和维护 CDC，不创建 USB HID 或扬声器；
- Companion 使用跨进程锁，同一时间只允许一个 GUI、CLI 或登录自启实例写 BLE；
- 蓝牙连接和认证状态优先于 NVS 额度缓存，USB 插线不会伪装为蓝牙连接；
- 维护串口使用 1200 波特触发进入 ROM，刷写后使用看门狗复位返回应用；
- 电池图标、填充和百分比经过圆盘几何边界校验，全部位于中央圆盘内。

每次发布前仍要在实机上确认触摸手感、扬声器主观音色、Mac 端 Codex 命令映射，以及 USB 录音是否产生真实非零音频。
