# Codex Micro 不可回退清单

这份清单是本设备后续每次修改、编译和刷机前的固定基线。界面调整不得以删除既有功能或设置为代价。

## 首页与视觉

- 360×360 圆屏，首页以用户指定的 2026-08-06 稳定版打包文件为基础并放大：六键轨道
  半径 132、圆键尺寸 86、中央额度环尺寸 176、额度数字字号 48，保留原中央圆盘和纯黑背景。
- 六个 Agent 圆键固定显示 `1–6`，单击立即执行；状态色填充整颗按钮。
- 中央为全圆额度环。取得真实额度后始终显示数字百分比和中文重置时间。
- Companion 尚未在当前蓝牙连接中发送数据时中央显示“等待连接”；Companion 已发送数据但未同步额度时显示“未同步额度 / 等待额度”。USB 只保留供电、刷机和串口，不参与 Codex 传输。
- 动态标题和工作区只要包含字库不支持的字符，整行隐藏；不替换为 `?` 或方框。
- 不绘制外围仪表、刻度、小状态点、扫描条、旋转扫描圈、边缘旋钮或 3/4/5 周围的装饰圆。
- 首页不再叠加反应堆外扩光晕；Agent 状态换色和点击缩放仍保持平滑、克制。
- 固定使用青蓝贾维斯能量色，不提供主题选择器；点击缩放和状态换色使用短促、平滑、克制的缓动。

## 操作

- `1–6`：立即发送 `AG01–AG06`。
- 长按 `1–6`：显示对应 Agent 的中文状态、动态标题/工作区和运行时间约 5 秒。
- 主页中央圆环按住约 0.8s 进入六快捷键页，按住约 5s 进入四向摇杆，按住约 10s 重新配对蓝牙，持续 20s 恢复出厂；界面出现后松手确认，在快捷/摇杆页单击中央返回主页。
- 快捷页不自动退出；中间单击才退出快捷页。
- 摇杆中点单击 1 次：退出摇杆。
- 遥控上方使用原生摇杆上推创建新任务；下方使用摇杆下推切换侧边栏。
- 遥控右/左分别发送 `ENC_CC` / `ENC_CW` 单步旋钮事件，Codex 中选定的旋钮模式决定前进/后退的实际行为。
- 不使用顺逆时针握持、边缘旋钮或隐藏滑动手势发送命令。
- 中央持续按住 20 秒才恢复出厂；约 10 秒起显示“重新配对”，15 秒起显示恢复出厂倒计时。

## 录音、屏幕与传感器

- BOOT 按住/松开控制录音；保留双击免按住录音和再次单击停止。
- 录音期间主页、Agent、额度、连接、电量、命令页和摇杆全部隐藏，只显示中文计时和真实麦克风波形。
- 波形保持居中的柔和基础动态，并叠加真实麦克风能量；随声音强弱和节奏变化，20ms 更新一次。
- 通电期间屏幕保持固定工作亮度；短按硬件 PWR 关机，不自动降亮度或熄屏。
- QMI8658 只负责移动唤醒与翻面静音；自动旋转已按用户要求关闭，屏幕保持默认方向。
- 移动唤醒和翻面静音覆盖所有页面；因自动旋转关闭，LVGL 不再变换触控坐标。

## 连接、状态和设置

- 保留 BLE Vendor HID、六 Agent 状态、发送、快速、同意、拒绝、分支、新任务、摇杆、录音和电量上报。
- 保留断线重新广播、唯一设备 ID、加密 companion 特征、额度缓存和 20 秒恢复出厂。
- 保留开机自检、完成、待处理和错误提示音；所有按钮、录音启停、遥控和恢复出厂均无点击音。屏幕朝下才静音，翻回朝上恢复，companion 声音开关仍共同生效。
- 最近额度、同步间隔和声音开关写入 NVS；普通应用区刷机与重启后恢复。
- 不提供“关闭额度显示”或多主题换色设置；Agent 状态颜色仍按真实状态平滑变化。
- 普通迭代只写应用区 `0x10000`，不擦除 NVS 和蓝牙绑定；只有明确执行恢复出厂才清空。

## 每次交付前

1. 运行 `scripts/check-regressions.sh`。
2. 编译 `waveshare-1_85b`。
3. 仅刷入应用区并确认写入哈希校验通过。
4. 串口确认启动标记、QMI8658、BLE 状态和 NVS 恢复日志。
5. 实机逐页检查首页、命令页、摇杆、录音、详情、倒计时、蓝牙重新配对和触控。
6. 更新固件、完整镜像、SHA256、源码包和 README，旧包不得继续标为当前版。
