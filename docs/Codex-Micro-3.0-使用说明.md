# Codex Macro32 V3 使用说明

V3 适用于 Waveshare ESP32-S3-Touch-LCD-1.85B 圆屏开发板，当前只支持并测试 macOS。它通过蓝牙控制 Codex，通过 Companion 同步额度和任务信息。插入 USB 数据线后，设备同时供电、充电并作为 Mac 的麦克风输入。

## 安装 V3

需要 Python 3、PlatformIO 和一根支持数据传输的 USB 线。

```sh
cd firmware/Codex-Micro-3.0
python3 -m pip install platformio
./scripts/check-regressions.sh
./flash.command
```

`flash.command` 会构建默认的 USB 麦克风版，随后只写 `0x10000` 应用区。NVS、蓝牙绑定、额度缓存和 Companion 设置都会保留。多个串口同时存在时，可以明确指定设备。

```sh
./flash.command /dev/cu.usbmodemNNN
```

已经运行新版 V3 的设备会通过维护串口自动进入 ROM 下载器，刷完后使用看门狗复位返回应用。旧固件没有维护串口时，第一次迁移需要手动进入 ROM 下载模式。

1. 关机并拔掉 USB。
2. 按住 BOOT 不松。
3. 插入 USB 数据线。
4. 等待约两秒后松开 BOOT。
5. 再次运行 `./flash.command`。

## 蓝牙与 Companion

刷入后在 macOS 的蓝牙设置中配对 `Codex Micro`，然后重新打开 ChatGPT Desktop。ChatGPT/Codex 需要输入监控权限才能接收控制命令。

图形界面的启动方式如下。

```sh
cd firmware/Codex-Micro-3.0/companion
./launch_companion.command
```

Companion 负责同步周额度、重置时间、最近六个任务和设备提示音开关。它默认每 300 秒同步一次，也可以在 GUI 中点击“立即同步”。

GUI、命令行和登录自启共用一个进程锁。已有一个 Companion 运行时，新实例会显示占用状态并停止启动，不会争抢 BLE 写连接。

## 首页显示

| 区域 | 含义 |
| --- | --- |
| `1` 到 `6` | 六个 Agent，点击立即切换 |
| 蓝色整球 | 运行中 |
| 绿色整球 | 已完成 |
| 黄色整球 | 等待处理 |
| 红色整球 | 报错 |
| 灰蓝色整球 | 空闲或未分配 |
| 中央数字 | 周额度剩余百分比 |
| 中央下方 | 额度重置时间和电量 |

额度环在剩余 50% 及以上时显示绿色，20% 到 49% 显示黄色，低于 20% 显示红色。

连接状态的优先级高于额度缓存。

| 蓝牙状态 | 中央文字 |
| --- | --- |
| 未连接、重配中、尚未完成认证 | `等待连接` |
| 已连接并认证，尚未取得额度 | `未同步额度` 和 `等待额度` |
| 已连接并取得额度 | 百分比和重置时间 |

历史额度仍保存在 NVS 中，蓝牙断开时不会用它冒充在线状态。动态任务标题或工作区含有设备字库不支持的字符时，整行隐藏，不显示方框或问号。

## 全部操作

| 操作 | 结果 |
| --- | --- |
| 点击 `1` 到 `6` | 切换对应 Agent |
| 长按 `1` 到 `6` | 显示该 Agent 的标题、工作区、状态和运行时间 |
| 中央短点 | 发送当前输入 |
| 中央按住 0.8 到 4.9 秒后松手 | 进入六快捷页 |
| 中央按住 5 到 9.9 秒后松手 | 进入四向摇杆页 |
| 中央按住 10 到 19.9 秒后松手 | 清除旧蓝牙绑定并重新广播 |
| 中央持续按住 20 秒 | 清除 NVS、绑定、额度和设置后重启 |
| 快捷页或摇杆页点击中央 | 返回首页 |
| 按住和松开 BOOT | 开始和结束 Push-to-talk |
| 350 ms 内双击 BOOT | 锁定录音，再按一次停止 |

六快捷页包含“快速”“同意”“拒绝”“分支”“录音”“发送”。页面不会自动退出。点击“录音”后进入独占波形界面，波形会跟随真实麦克风能量变化。按一次 BOOT 结束。

摇杆页上方创建新任务，下方切换侧边栏，右侧发送 `ENC_CC`，左侧发送 `ENC_CW`。左右的实际行为跟随 Codex 中选定的旋钮模式。界面没有边缘旋钮、隐藏滑动或握持旋转操作。

## USB 麦克风

插线后，macOS 的输入设备中会出现 `Codex Macro32 Mic`。它使用板载 ES7210 双麦克风，输出 48 kHz、16 位、单声道音频。USB 不暴露键盘、Vendor HID 或扬声器。Codex 命令和额度仍然只走蓝牙。

Companion 默认在麦克风插入时把它设为 macOS 默认输入，拔出时恢复此前输入。连接期间手动选择其他麦克风后，Companion 会保留手动选择。

Mac 正在读取 USB 麦克风时，设备会延后任务提示音，等麦克风流释放后再播放，尽量避免扬声器声音混入录音。

## 声音、屏幕和传感器

- 普通按键、录音启停和摇杆操作都没有按键音。
- 任务完成播放绿色对应的完成音。
- 等待处理播放黄色对应的提醒音。
- 报错播放红色对应的警告音。
- 屏幕朝下时静音，翻回朝上后恢复。
- 设备通电期间保持常亮，短按硬件 PWR 键关机。
- 自动旋转已关闭。QMI8658 只保留移动唤醒和翻面静音。

## 常见问题

### 设备显示“等待连接”

先在 macOS 蓝牙设置中确认 `Codex Micro` 已连接。重置蓝牙后，Mac 保留的旧绑定可能已失效。在系统设置中忽略旧设备，然后重新配对。

### 设备显示“未同步额度”

这表示蓝牙已连接并完成认证，Companion 还没有写入有效额度。打开 Companion，确认 Codex 已登录，然后点击“立即同步”。

### Companion 提示已有实例运行

电脑上已经有 GUI、命令行或登录自启中的一个实例。保留其中一种启动方式即可。

### Mac 看不到 `Codex Macro32 Mic`

确认使用支持数据传输的 USB 线，并确认刷入的是 V3 默认 USB 麦克风版。拔插一次数据线，再打开“系统设置”中的“声音”和“输入”查看。

### 界面出现方框或缺字

记录具体页面和文字。静态中文应全部在自定义字库内，动态标题遇到缺字时应整行隐藏。当前版本不使用问号代替缺字。
